STAC Lens

See the shape of your STAC data — structure, time, and space as one coordinated view.

STAC Lens is a free, open-source, browser-only viewer and health checker for STAC (SpatioTemporal Asset Catalog) catalogs and APIs — the open standard for Earth observation, remote sensing and other geospatial data. Paste a catalog URL and it draws how the publisher organized the data, what it covers in time and space, where the metadata contradicts itself or the specification, and what the API really does when asked. Nothing is uploaded: every request goes from your browser to the catalog you open.

  • Choosing a data source? See a catalog's shape, coverage and API behavior before writing code against it.
  • Publishing a catalog? See the structure you shipped with the problems marked — what the JSON does, not only whether it validates.
  • Learning STAC? Catalog → Collection → Item, extents, links and API capabilities as one visual language.
